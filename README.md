# Cute Pastry & Dessert Shop

A delightful, cartoon-themed pastry shop game built with Flutter. Serve your customers by stacking their custom cake orders layer by layer before their patience runs out!

## Features
- **Real-Time Customer Queue:** Customers arrive dynamically with layered cake orders.
- **Decreasing Patience:** Each customer has a patience bar that slowly depletes. Serve them in time or they leave!
- **Layer-by-layer Building:** Stack Sponge, Choco Base, Matcha, Cream, Berries, Ganache, Macaron, and Cherry ingredients perfectly to match customer requests.
- **Responsive Design:** Optimized layout for both narrow mobile/embedded screens and wider desktop/tablet views.
- **Cute Aesthetics:** Uses a specific pastel palette and playful 3D buttons for a charming feel.

## Tech Stack
- **Flutter / Dart:** Cross-platform app framework for web, mobile, and desktop.

## Setup & Run
Make sure you have Flutter installed. Then run:
```bash
flutter pub get
flutter run
```
