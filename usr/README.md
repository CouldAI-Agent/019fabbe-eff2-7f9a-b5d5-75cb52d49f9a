# Cute Cartoon Pastry & Dessert Shop

A cute web-based game built with HTML, CSS, and JavaScript where players fulfill dessert orders for waiting customers. Build cakes layer-by-layer and manage the customer queue!

## Features
- Real-time customer queue with patience bars.
- 8 unique ingredients to build delicious cakes.
- Matching logic to serve correct orders.
- Score tracking and dynamic queue management.
- Responsive, pastel-colored, cute UI.

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## Setup / Run Instructions
Open `web/index.html` in any modern web browser to play the game!
